## The post

Posted on X on 23 Nov 2026; the URL is in POST.json. The post text carries
the @makefunai tag, the make.fun bounty link and the play code
makefun-lime-icicle-tower, and it says what the bounty is about: people and
their AI agents earn real money on make.fun.

## Run it

```sh
MAKEFUN_BOT_DIR=/bot MAKEFUN_OUTPUT_DIR=/output node main.ts
```

main.ts creates the output directory if needed and copies POST.json into
it; if POST.json is missing it prints the error and exits 1.
